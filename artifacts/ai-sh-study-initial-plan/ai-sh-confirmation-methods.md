# Anytime SH 独立复测与排名奖励实验

2026-10-27，在查看新种子结果前固定。

## 组别

1. sh200：Anytime SH vs UCT，双方 200ms。20 个新种子 810001–810020，2–5 人，每个座位轮换一次，共 280 局。原版估值、策略、相对分差奖励、单纪元终点不变，使用冻结 ABI5。
2. sh500：同样种子和座位，双方 500ms，共 280 局，使用同一个冻结 ABI5。无论第一组结果如何均完成，用于预算对照；不根据前组结果调参。
3. rank200：Anytime SH + future-rank 奖励 vs Anytime SH + 原相对分差奖励，双方 200ms。另一批种子 840001–840020，同样轮换，共 280 局。其他设置一致，使用 ABI6；先确认 ABI6 默认奖励固定预算与冻结 ABI5 完全一致。

## 主指标与推断

主指标：每个人数分别求平均排名；归一化排名分 (人数−名次)/(人数−1)，再对 2/3/4/5 人等权平均。等强参考 50%。次指标为首名次数、分差及实际搜索成本。

只对完整组做正式推断。以种子为区组，固定随机种子的 100000 次 bootstrap，给出 95% 区间；三组同时报告 Bonferroni 98.333% 区间。另用配对种子 bootstrap 比较 sh500−sh200，但不同预算的时间搜索不能保证轨迹逐步配对。预先以 sh200 的 95% 区间下限超过 50% 作为此次独立复测支持优势的标准；其余结果按确认性/探索性分别解释。不得按中途排名提前停止或改种子。

## 排名奖励的定义与边界

所有玩家累计分在搜索起点仍统一为 100，不读取真实隐藏分数、牌袋次序或种子，不从历史恢复私有分数。叶节点评分仍为：本次模拟新增得分 + 原有未来估值。对于每个玩家，取其叶节点评分超过其他玩家的比例；同分记半分。报告候选 value 为该比例的均值，搜索回传效用为 2×比例−1，维持 [-1,1] 范围。原奖励保持 tanh(相对分差/20) 不变。

这比较的是“后续预测得分的排名代理目标”，不是全局最终名次的精确概率。以同分半分体现评分代理的不确定性；正式对局最终名次仍按引擎最高圆盘破同分。排名奖励同时改变效用形状与离散程度，若有效仍需进一步分离这两种影响。

## 留存与运行

每局完整行动、搜索候选/访问/估值、实际耗时、终局排名、动作 SHA256 与构建 SHA256 全部保存；写盘前正式引擎重放验证完整状态。断点只在完整对局后保存，未完成对局重跑；不把重跑当作同一时间搜索轨迹。

并发最多 8 个 Worker；每次搜索是软墙钟预算，完成当前模拟并覆盖根候选后才停止。报告实际耗时、模拟数、超时量，不把标称预算写成严格相同 CPU 时间。三组顺序运行，训练和回归检查尽量在正式对战开始前完成。所有实验选项默认关闭，生产默认仍为 UCT / 原奖励。
