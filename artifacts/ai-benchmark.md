# Ra AI 强度验证

2026-10-25。本机执行；基础版 2–5 人。每局只有一个新版进阶 AI，其余均为指定对照策略。每个种子把新版轮换到全部座位；按最终累计分及最高太阳圆盘判定赢家。

## 验证及解释

- 完整测试 30 项通过，含 36 场全 AI 比赛逐步检查牌与圆盘守恒；本次调整标准难度后，另复查 29 项测试，含 2–5 人模拟与实际规则引擎逐步一致性。
- 生产构建通过；浏览器独立测试端口验证了进阶 Worker 抽牌、竞价、成交、继续行动和暂停，未见控制台错误。
- 验证对手是机器人，种子数量有限且轮换座位的样本相关，不代表对熟练真人的已标定胜率。仍需要真人实战评测。
- 五人局对新版标准的胜率为 50%，说明算法还有改进空间。当前目标是有挑战性的本地对手，不宣称必胜或竞技顶级水平。

## 标准难度的独立对照

新版标准对旧版进阶，使用种子 4001–4004 并轮换全部座位，赢得 **28/56** 场。此项验证不使用蒙特卡洛搜索，计算耗时中位数约 0.04 ms，适合作为快速难度。

## 原始报告与复现

- `ai-vs-legacy.json`：56 场逐局结果及耗时。
- `ai-vs-policy.json`：28 场逐局结果及耗时。
- `ai-standard-vs-legacy.json`：标准难度独立验证。
- `ai-pilot.json`：独立的初步试跑。

```bash
npm run benchmark:ai -- --seeds 4 --start 2001 --out artifacts/ai-vs-legacy.json
npm run benchmark:ai -- --seeds 2 --start 3001 --opponent policy --out artifacts/ai-vs-policy.json
npm run benchmark:ai -- --candidate policy --seeds 4 --start 4001 --out artifacts/ai-standard-vs-legacy.json
npm test
npm run build
```

- 新版标准对照：中位数 52.7 ms；P95 277.2 ms；最长 620.7 ms。
