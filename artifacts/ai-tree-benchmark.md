# SH / DPW 对照结果

实验日期：2026-10-26。

没有一种方法在固定预算和等时两组都获得高于等强参考的第一名次数；本次结果不支持直接替换默认搜索。

## 设计与完整性

六个新种子 14001–14006，2–5 人全部座位，四组各 84 局，共 336 局全部完成。每局只有一个候选，其余为 UCT。估值、对手策略、收益函数、场景采样和单纪元终点保持一致。固定预算双方总模拟预算为根候选数 × 32 次，由各搜索策略分配；等时双方每步 200 ms 软时限。固定预算 SH 使用 Sequential Halving，等时 SH 使用 Anytime 调度，两者分别报告，不混为同一个测试配置。DPW 使用统一宽度 `ceil(2 * sqrt(visits + 1))`，根候选全部保留。

参数、研究引用与信息隔离处理见 [实验设计](ai-tree-methods.md)。本报告脚本检查完整组别、种子、座位和无重复记录；所有行动经正式 TS 引擎验证执行，同分按最高圆盘判定。

## 等时预算是否生效

下表仅计实际执行搜索的调用，排除只有一个合法候选而直接返回的步骤。统计包含 JS 输入处理和结果解码。

| 组别 | 候选平均 ms | UCT 平均 ms | 候选超过 210 ms | UCT 超过 210 ms |
|---|---:|---:|---:|---:|
| Anytime SH / 200 ms | 200.83 | 200.89 | 0.0% | 0.1% |
| DPW / 200 ms | 201.43 | 200.88 | 0.1% | 0.1% |

200 ms 为相同的软计算时限，在完整模拟间检查，并保证每个根候选至少评估一次。因此实际时间包括末次模拟、桥接与操作系统调度开销，不是严格相等的 CPU 时间。并发线程共用交错组别队列，减少组别与机器负载时段的相关性；时钟预算下的模拟次数和结果不能保证逐次完全重现。固定预算模式保持确定性。
